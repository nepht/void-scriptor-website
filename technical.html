BUKTI & BATAS

Bukti teknis yang dapat diperiksa sekarang.

Sidik jari file (SHA-256)

Nilai SHA-256 tersedia sebagai teks statis di manifest lokal. Nilai yang cocok berarti isi file sama dengan yang dipublikasikan; itu belum membuktikan asal file.

Konfigurasi uji

Konfigurasi uji yang tersedia adalah Windows 11 Pro 64-bit, Intel Core i5-4570, RAM 32 GiB, dan AMD Radeon RX590 GME. Ini bukan persyaratan minimum resmi; minimum CPU, RAM, GPU, dan ruang disk belum ditetapkan. Baca Konfigurasi uji.

Tanda tangan file

Pemeriksaan lokal RC.2 mengembalikan Status: Valid dengan waktu penandatanganan. Sertifikatnya diterbitkan sendiri, jadi integritas tanda tangan dapat diperiksa, tetapi identitas penerbit belum dipercaya SmartScreen.

Keamanan

API website tidak menerima permintaan dari semua asal secara bebas. Koneksi Byte lokal memiliki daftar asal yang diizinkan. Pengaturan isolasi browser belum diklaim kompatibel penuh tanpa verifikasi login OAuth dan koneksi lokal; laporan keamanan ada di security.txt.

DETAIL TEKNIS

Penyimpanan dan koneksi yang terukur.

Data aplikasi

Status masuk dan laporan kesalahan disimpan di folder dukungan aplikasi Windows, di dalam VoidScriptor\state dan VoidScriptor\diagnostics\crash. Lokasi folder dapat berbeda menurut konfigurasi Windows.

Proyek

Jika Anda tidak memilih lokasi sendiri, folder utama proyek berada di Documents, di dalam VoidScriptor\Projects. Lokasi pilihan Anda menjadi acuan utama; jika drive tidak tersedia, aplikasi memberi tahu bahwa lokasi cadangan sedang dipakai.

Cara masuk dan koneksi Byte

Website memakai GitHub atau Google untuk masuk. Cookie sesi tidak berisi kata sandi. Koneksi Byte opsional berjalan di komputer Anda pada 127.0.0.1:8766 dan menerima permintaan dari alamat yang diizinkan.
