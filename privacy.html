Kebijakan Privasi

Berlaku sejak: 7 Oktober 2026 · Terakhir diperbarui: 7 Oktober 2026 (revisi bagian akun & login)

Ringkas: Kami tidak menjalankan pelacakan iklan, tidak menjual data Anda, dan tidak memakai cookie pihak ketiga. Untuk masuk, kami memakai GitHub atau Google: penyedia itu membagikan nama, email, dan foto profil Anda kepada kami, dan kami menyimpannya di cookie sesi bertanda tangan selama 24 jam agar situs mengenali Anda. Cookie dihapus oleh Keluar hanya pada peramban ini; sesi yang tersalin di perangkat lain tetap berlaku sampai kedaluwarsa. Kami tidak menyimpan kata sandi, tidak menyimpan token akses, dan tidak memiliki basis data akun.

01Data yang kami proses

Kami berupaya memproses data sesedikit mungkin (data minimization):

  • Data akun (masuk dengan GitHub/Google): saat Anda masuk, penyedia identitas membagikan ID akun, nama tampilan, nama pengguna, alamat email, dan URL foto profil Anda kepada kami. Kami memakainya hanya untuk menampilkan identitas Anda di situs, dan menyimpannya di cookie sesi (lihat bagian 03). Kami tidak pernah menerima atau menyimpan kata sandi Anda, dan tidak menyimpan token akses OAuth : token itu dipakai sekali di server untuk membaca profil Anda, lalu dibuang. Kami tidak memiliki basis data akun: satu-satunya salinan data profil Anda ada di cookie di peramban Anda.
  • Preferensi bahasa: pilihan ID/EN disimpan di peramban Anda.
  • Log server: penyedia hosting (Cloudflare) secara otomatis mencatat data teknis standar seperti alamat IP, jenis peramban, dan waktu akses untuk keamanan dan pencegahan penyalahgunaan.

In short: no ad trackers, no third-party cookies, no data selling. Sign-in uses GitHub or Google, which shares your name, email and avatar with us; we keep those in a signed session cookie for 24 hours so the site can recognise you. Signing out clears the cookie only in this browser; a copied session on another device remains valid until it expires. We never store your password, never keep the OAuth access token, and hold no account database.

02Cara kami menggunakan data

  • Menjalankan dan mengamankan situs (deteksi serangan, penyalahgunaan, dan lonjakan trafik).
  • Mengenali Anda saat sudah masuk (sesi akun) dan mengingat preferensi bahasa Anda.
  • Menjawab pertanyaan yang Anda kirim melalui email dukungan.

03Cookie & penyimpanan lokal

Kami tidak memakai cookie untuk periklanan atau pelacakan lintas situs, dan tidak ada cookie pihak ketiga.

  • Cookie sesi (vs_session): diisi hanya setelah Anda masuk. Isinya adalah data profil publik Anda (nama, nama pengguna, email, foto) beserta waktu masuk dan waktu kedaluwarsa, ditandatangani secara kriptografis (HMAC-SHA256) sehingga tidak dapat diubah orang lain. Bersifat HttpOnly, Secure, dan SameSite=Lax : tidak dapat dibaca oleh skrip halaman dan berlaku 24 jam, setelah itu Anda otomatis keluar.
  • Cookie state OAuth (vs_oauth_state): berumur pendek (10 menit) dan hanya dipakai untuk mencegah serangan CSRF selama proses masuk. Cookie ini dihapus begitu proses selesai.
  • localStorage: menyimpan preferensi bahasa (ID/EN), preferensi Byte, kemajuan checklist, dan ringkasan metadata ruang kerja bila Anda menggunakannya. Data ini tetap di peramban Anda dan tidak menjadi basis data akun.

Menekan Keluar menghapus cookie sesi dari peramban ini seketika. Jika sesi mungkin pernah tersalin ke perangkat lain, cabut izin aplikasi di pengaturan GitHub atau Google. Anda juga dapat menghapus seluruh cookie dan data situs ini kapan saja melalui pengaturan peramban.

04Pihak ketiga

Situs ini dihosting oleh Cloudflare Pages, dan halaman unduhan dilayani melalui Cloudflare R2. Cloudflare memproses data teknis sesuai kebijakan privasinya sendiri.

  • GitHub : bila Anda memilih masuk dengan GitHub, profil Anda diproses sesuai kebijakan privasi GitHub.
  • Google : bila Anda memilih masuk dengan Google, profil Anda diproses sesuai kebijakan privasi Google.

Kami tidak mengintegrasikan jaringan iklan, analitik pihak ketiga, atau pixel pelacakan.

05Hak Anda

Kami tidak memiliki basis data akun, sehingga tidak ada data profil Anda yang tersimpan di server kami untuk diakses, diperbaiki, atau dihapus. Profil sesi berada di cookie peramban Anda; preferensi dan ringkasan Byte berada di penyimpanan lokal peramban, dan Anda memegang kendali penuh:

  • Melihat & mengunduh data Anda: tombol Unduh data saya di dasbor menyalin seluruh isi sesi Anda (nama, nama pengguna, surel, penyedia, dan waktu sesi) ke sebuah berkas JSON di perangkat Anda. Tidak ada data yang dikirim ke server untuk ini.
  • Menghapus data akun: tombol Hapus data saya di dasbor menghapus data lokal dashboard dan cookie sesi pada peramban ini. Tombol Keluar hanya menghapus cookie sesi; untuk sesi yang tersalin atau akses aplikasi, cabut izin di penyedia identitas.
  • Mencabut akses aplikasi: Anda dapat mencabut izin Void Scriptor kapan saja dari pengaturan akun GitHub atau Google Anda (dasbor menyediakan tautan langsung), sehingga kami tidak lagi dapat membaca profil Anda.
  • Preferensi bahasa: dapat Anda ubah atau hapus melalui pengaturan peramban.

Untuk pertanyaan tentang privasi atau permintaan terkait data, hubungi kami di voidscriptor@gmail.com.

06Anak-anak

Layanan ini tidak ditujukan untuk anak di bawah usia 13 tahun. Kami tidak dengan sengaja mengumpulkan data anak-anak.

07Perubahan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan material akan ditandai dengan pembaruan tanggal "Terakhir diperbarui" di atas.
