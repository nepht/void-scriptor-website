01Data yang kami proses

Kami berupaya memproses data sesedikit mungkin (data minimization):

  • Data akun (masuk dengan GitHub/Google): saat Anda masuk, layanan login membagikan ID akun, nama tampilan, nama pengguna, alamat email, dan URL foto profil Anda kepada kami. Kami memakainya untuk mengenali akun, menampilkan identitas, dan menghubungkan website dengan aplikasi yang memakai layanan akun yang sama. Profil akun, data login, kode masuk sekali pakai, dan sesi aktif disimpan di Cloudflare D1. Kami tidak pernah menerima atau menyimpan kata sandi, dan tidak menyimpan token akses GitHub/Google: token layanan login hanya dipakai sekali di server untuk membaca profil lalu dibuang. Aplikasi menerima token sesi Void Scriptor yang acak, berumur 24 jam, dan dapat dicabut di server.
  • Google Drive (opsional): bila Anda memilih Hubungkan Google Drive, server menerima refresh token Google Drive untuk membuat access token sementara saat mengunggah snapshot. Refresh token disimpan dalam bentuk yang dienkripsi menggunakan secret Worker dan tidak pernah dikirim ke browser atau ditampilkan di API. Kami menyimpan referensi file backup yang dibuat aplikasi, bukan isi ruang kerja; file remote bernama voidscriptor-account-backup.json dan hanya berisi snapshot akun yang sudah Anda simpan. Memutuskan koneksi menghapus kredensial lokal dari D1, tetapi tidak menghapus file remote.
  • Profil yang Anda isi sendiri: dasbor dapat menyimpan nama tampilan, username publik, bio singkat, bahasa akun, zona waktu, pilihan visibilitas profil, alias QOWNER, dan pilihan ikut leaderboard. Username dan profil hanya ditampilkan di halaman publik jika Anda memilih visibilitas Publik; email dan provider login tidak pernah ditampilkan di sana. Alias QOWNER hanya dapat ditampilkan untuk leaderboard jika Anda memilih izin tersebut.
  • Minat rilis QOWNER (opsional): jika Anda mengisi email dan mencentang persetujuan di halaman QOWNER, kami menyimpan alamat email yang sudah dinormalisasi, sumber formulir, waktu persetujuan, serta waktu pembaruan di Cloudflare D1. Data ini hanya untuk menindaklanjuti kabar rilis QOWNER; belum ada email otomatis yang dikirim dan alamat tersebut tidak ditampilkan secara publik.
  • Preferensi bahasa: pilihan ID/EN disimpan di peramban Anda.
  • Log server: penyedia hosting (Cloudflare) secara otomatis mencatat data teknis standar seperti alamat IP, jenis peramban, dan waktu akses untuk keamanan dan pencegahan penyalahgunaan.
  • Byte dan ruang kerja lokal: pesan yang Anda kirim ke Byte, pilihan karakter/suara, serta ringkasan metadata yang Anda minta untuk dibaca (nama, tipe, ukuran, ekstensi, dan waktu perubahan berkas). Bridge lokal tidak mengirim isi berkas untuk pemindaian; ringkasan dapat diteruskan ke model AI lokal atau penyedia model yang Anda konfigurasi untuk menyusun jawaban.
  • Suara: keluaran suara Byte dibuat oleh kemampuan suara di peramban. Jika Anda menyalakan mikrofon, pengenalan suara mengikuti pemrosesan yang disediakan oleh peramban/perangkat Anda; kami tidak menyimpan rekaman suara melalui situs ini.
  • Produk mendatang: jika Studio atau QOWNER mengaktifkan analitik, telemetri, crash report, leaderboard, atau data progres tersimpan di server, jenis data dan tujuannya akan dijelaskan sebelum fitur tersebut aktif.

In short: no ad trackers, no third-party cookies, no data selling. Sign-in uses GitHub or Google, which shares your name, email, avatar, and provider ID with us. We store the account identity in Cloudflare D1 for the website. Google Drive is optional; if you connect it, we store an encrypted Drive refresh token and upload only the account snapshot you explicitly save. App connection is not active yet. 03Cookie & penyimpanan lokal

Kami tidak memakai cookie untuk periklanan atau pelacakan lintas situs, dan tidak ada cookie pihak ketiga.

  • Cookie sesi (vs_session): diisi hanya setelah Anda masuk. Isinya adalah rujukan sesi acak, ID akun, provider, dan waktu kedaluwarsa yang ditandatangani di server supaya tidak bisa diubah diam-diam; token OAuth tidak pernah dimasukkan. Rujukan sesi disimpan sebagai hash di D1, sehingga dapat dicabut di server. Cookie bersifat HttpOnly, Secure, dan SameSite=Lax, serta berlaku hingga 24 jam setiap kali diterbitkan atau diperbarui. Sesi browser diperbarui otomatis saat tetap digunakan dan mendekati kedaluwarsa.
  • Cookie state OAuth (vs_oauth_state): berumur pendek (10 menit) dan hanya dipakai untuk mencegah serangan CSRF selama proses masuk. Cookie ini dihapus begitu proses selesai.
  • Cookie penghubungan provider (vs_oauth_link): hanya muncul ketika Anda meminta menghubungkan Google atau GitHub kedua ke akun yang sedang aktif. Cookie ini ditandatangani, berlaku paling lama 10 menit, dan terikat pada hash sesi aktif; token provider tetap diproses sekali di server lalu dibuang.
  • Cookie alur aplikasi (vs_oauth_flow): hanya muncul saat aplikasi memulai login, berumur paling lama 10 menit, ditandatangani, dan mengikat balasan login ke aplikasi serta pemeriksaan keamanan. Kode yang diterbitkan setelah login berlaku 2 menit dan hanya dapat dipakai sekali; nilai mentahnya tidak disimpan.
  • Cookie alur Google Drive (vs_google_drive_state): berumur paling lama 10 menit, ditandatangani, dan terikat pada akun serta sesi yang sedang masuk. Cookie ini hanya mengamankan callback persetujuan Drive dan dihapus setelah alur selesai; refresh token tidak disimpan di cookie.
  • Sesi aplikasi: aplikasi menyimpan token sesi Void Scriptor yang acak di penyimpanan aman perangkat. Token berlaku paling lama 24 jam, dikirim ke endpoint akun, dan dapat dicabut melalui Keluar.
  • localStorage: menyimpan preferensi bahasa (ID/EN), preferensi Byte, kemajuan checklist, dan ringkasan metadata ruang kerja bila Anda menggunakannya. Data ini tetap di peramban Anda dan tidak menjadi basis data akun.

Menekan Keluar mencabut sesi ini di server dan menghapus cookie dari peramban ini. Sesi pada perangkat lain tetap terpisah; keluar dari perangkat tersebut atau cabut izin aplikasi di pengaturan GitHub/Google bila diperlukan. Anda juga dapat menghapus seluruh cookie dan data situs ini kapan saja melalui pengaturan peramban.

Jika kunci tanda tangan sesi diduga bocor, kami dapat merotasi SESSION_SECRET; tindakan itu membatalkan seluruh cookie sesi yang ada dan memaksa semua pengguna masuk kembali. D1 juga memungkinkan sesi individual yang tersimpan dicabut tanpa menghapus akun.

04Pihak ketiga

Situs ini dihosting oleh Cloudflare Pages, profil akun dan sesi dikelola melalui Cloudflare D1, dan halaman unduhan dilayani melalui Cloudflare R2. Cloudflare memproses data teknis dan akun sesuai peran serta kebijakan privasinya sendiri.

  • GitHub : bila Anda memilih masuk dengan GitHub, profil Anda diproses sesuai kebijakan privasi GitHub.
  • Google : bila Anda memilih masuk dengan Google, profil Anda diproses sesuai kebijakan privasi Google.
  • Google Drive API : bila Anda mengaktifkan backup Drive, permintaan unggah diproses oleh Google sesuai kebijakan privasi Google. Scope yang diminta dibatasi pada file yang dibuat oleh aplikasi.

Kami tidak mengintegrasikan jaringan iklan, analitik pihak ketiga, atau pixel pelacakan.

Cloudflare Pages/D1/R2, GitHub, Google, dan penyedia email dapat memproses data dari atau di luar Indonesia. D1 akun Void Scriptor dibuat di region APAC; pemrosesan lain tunduk pada peran, kebijakan, dan mekanisme transfer yang mereka gunakan.

  • Sesi web: diperbarui otomatis selama Anda tetap aktif; tanpa pembaruan, masa berlaku paling lama 24 jam sejak penerbitan atau pembaruan terakhir, atau sampai dicabut. Sesi aplikasi tetap berlaku paling lama 24 jam. OAuth state dan alur aplikasi sampai 10 menit; kode pertukaran aplikasi sampai 2 menit atau satu kali pemakaian. Catatan yang sudah kedaluwarsa dibersihkan sebagai bagian dari operasional database.
  • Profil akun dan identitas provider: selama akun aktif atau sampai Anda mengajukan penghapusan melalui Kontak, dengan pengecualian yang diperlukan untuk keamanan, sengketa, atau kewajiban hukum. Alias QOWNER dan pilihan leaderboard mengikuti masa penyimpanan profil dan dapat Anda ubah dari dasbor.
  • Preferensi dan ringkasan Byte: tetap di peramban sampai Anda menghapusnya atau memakai Hapus data saya.
  • Koneksi Google Drive: refresh token terenkripsi dan referensi file disimpan selama koneksi aktif. Memutuskan koneksi menghapus kredensial dari D1; file backup yang sudah dibuat tetap berada di Google Drive sampai Anda menghapusnya di sana.
  • Email dukungan: ditinjau dan disimpan selama diperlukan untuk menjawab, menjaga riwayat dukungan, atau memenuhi kewajiban; target operasionalnya paling lama 24 bulan setelah interaksi terakhir kecuali diperlukan lebih lama.
  • Minat rilis QOWNER: disimpan selama daftar rilis masih relevan atau sampai Anda meminta penghapusan. Kami dapat meninjau daftar tersebut secara berkala; permintaan penghapusan dapat diajukan melalui Kontak.
  • Log Cloudflare: kami tidak mengendalikan retensi teknis yang dikelola Cloudflare. Log yang tersedia bagi kami dipakai untuk keamanan dan operasional selama diperlukan; retensi aktual dapat mengikuti produk, paket, dan kebijakan Cloudflare.

Jika terjadi insiden keamanan yang berdampak pada data pribadi, kami akan menyelidiki, mengambil langkah pengamanan, dan memberikan pemberitahuan kepada pihak yang terdampak atau otoritas jika diwajibkan oleh hukum yang berlaku.

06Hak Anda

Kami menyimpan profil akun, data layanan login, dan catatan sesi minimum di Cloudflare D1 agar identitas website tetap tersambung. Jika Google Drive terhubung, Anda dapat memutuskan koneksi dari dasbor untuk menghapus token pembaruan terenkripsi dan referensi file dari D1; file yang sudah ada tetap perlu dihapus dari Google Drive. Koneksi aplikasi belum aktif; penggunaan identitas ini oleh aplikasi mendatang akan dijelaskan dan diverifikasi sebelum peluncuran. Preferensi dan ringkasan Byte tetap berada di penyimpanan lokal peramban. Anda dapat meminta akses, koreksi, atau penghapusan akun melalui Kontak:

  • Melihat & mengunduh data Anda: tombol Unduh data saya meminta ekspor terautentikasi yang berisi profil akun, provider terhubung, dan metadata sesi tanpa token rahasia, lalu menggabungkannya dengan data lokal Byte yang tersimpan di browser ke sebuah berkas JSON di perangkat Anda. Isi data lokal tidak dikirim ke server.
  • Menghapus data akun: tombol Hapus data lokal & keluar di dasbor hanya menghapus data lokal dan mencabut sesi pada peramban ini. Tombol Hapus akun dan data server menghapus profil akun, identitas provider, seluruh sesi, snapshot cloud, serta token Google Drive yang tersimpan setelah Anda mengetik konfirmasi eksplisit. File yang sudah dibuat di Google Drive tidak ikut dihapus; hapus file remote dari Google Drive jika itu juga Anda inginkan.
  • Mencabut akses aplikasi: Anda dapat mencabut izin Void Scriptor kapan saja dari pengaturan akun GitHub atau Google Anda (dasbor menyediakan tautan langsung), sehingga kami tidak lagi dapat membaca profil Anda.
  • Menarik persetujuan leaderboard: Anda dapat mengosongkan alias atau mematikan pilihan leaderboard QOWNER dari dasbor kapan saja. Fitur leaderboard akan memakai pilihan terbaru saat tersedia.
  • Menarik minat rilis QOWNER: kirim permintaan penghapusan ke voidscriptor@gmail.com. Sertakan alamat yang digunakan pada formulir; kami dapat meminta verifikasi yang wajar sebelum menghapusnya.
  • Preferensi bahasa: dapat Anda ubah atau hapus melalui pengaturan peramban.

Untuk pertanyaan tentang privasi atau permintaan terkait data, hubungi kami di voidscriptor@gmail.com.
