EVIDENCE & BATAS

Apa yang bisa diperiksa sekarang.

Checksum

SHA-256 tersedia sebagai teks statis di manifest lokal. Cocok berarti bytes cocok dengan nilai yang dipublikasikan; bukan bukti provenance.

Requirements

Konfigurasi uji yang tersedia adalah Windows 11 Pro 64-bit, Intel Core i5-4570, RAM 32 GiB, dan AMD Radeon RX590 GME. Ini bukan persyaratan minimum resmi; minimum CPU, RAM, GPU, dan ruang disk belum ditetapkan. Baca Konfigurasi uji.

Signing

Audit lokal RC.2 mengembalikan Status: Valid dengan timestamp. Sertifikatnya self-issued, jadi integritas tanda tangan dapat diperiksa tetapi identitas publisher tepercaya dan trust SmartScreen publik belum tersedia.

Security

API website tidak membuka CORS wildcard. Byte Bridge memiliki allowlist origin. COOP/CORP tidak dijadikan klaim kompatibilitas penuh tanpa verifikasi browser OAuth/bridge; laporan keamanan ada di security.txt.
