01 · INSTALL

Installing and verifying Studio.

These five steps are sequential. Do not skip verification, because the installer is still signed with a self-issued certificate.

01

Download from the canonical domain

Take the installer from the downloads page on voidscriptor.com. Do not use third-party mirrors.

02

Hash it and compare SHA-256

Hash the file and compare it with the checksum manifest. If it differs, delete the file and download it again.

03

Run the installer

Run the .exe as a normal user. There is no need to disable any system protection.

04

Understand the SmartScreen warning

The warning can appear because the certificate is self-issued. That is not proof the file is broken, but it is not a guarantee of safety either: the decision stays with you.

05

Uninstalling Studio

Open Settings → Apps, select Void Scriptor, then Uninstall. Projects in the Documents folder are not removed automatically.

Get-FileHash .\VoidScriptor-1.2.0-rc.2-windows-x64-setup.exe -Algorithm SHA256
02 · WORKFLOW

Five steps from idea to result.

This is the flow Studio uses, the same one described on the homepage. The order can be re-entered at any step when a project changes.

01

Capture the idea

Write the raw idea down first, before tidying it. This is where a project starts.

02

Shape the material

Turn notes into material you can use: settings, characters and rules.

03

Build the experience

Arrange the material into an order of chapters, scenes or questions.

04

Review and refine

Read the result again and tidy the parts that are still weak.

05

Export or share

Take the result out of the project so it can be used outside Studio.

03 · BYTE

Connecting Byte to your computer.

This step is optional. If you skip it, the homepage can still use a remote connection or offline mode.

  • The local connection runs only at 127.0.0.1:8766.
  • Only allowed addresses are accepted.
  • Never paste a token, cookie or secret into a bug report.

Full details are on the Byte Assistant page and in the Privacy Policy.

04 · CHECK A RELEASE

Checking the release you are using.

The version appears in the installer filename and on the release notes page. The official checksum is published as a plain-text manifest.

Get-FileHash .\VoidScriptor-1.2.0-rc.2-windows-x64-setup.exe -Algorithm SHA256

If the hash does not match the manifest, do not run the installer and report it through the bug report page.
