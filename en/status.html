EVIDENCE & LIMITS

What you can check now.

File fingerprint (SHA-256)

The SHA-256 value is available as static text in the local manifest. A matching value means the file contents are the same as the published file; it does not prove the file’s origin.

Tested configuration

The available tested configuration is Windows 11 Pro 64-bit, Intel Core i5-4570, 32 GiB RAM, and AMD Radeon RX590 GME. This is not an official minimum requirement; minimum CPU, RAM, GPU, and disk space have not been set. Read the tested configuration.

File signature

The local RC.2 check returned Status: Valid with a signing time. The certificate is self-issued, so signature integrity can be checked, but the publisher identity is not yet trusted by SmartScreen.

Security

The website API does not freely accept requests from every origin. The local Byte connection has an allowlist of origins. Browser isolation settings are not claimed to be fully compatible without verifying OAuth login and the local connection; security reports are listed in security.txt.
