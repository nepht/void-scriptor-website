PRODUCT · WINDOWS

A studio that keeps your work consistent.

Studio is a desktop creative tool for assembling worlds, characters, stories and quizzes inside one project. The current release is a release candidate for Windows x64, not a stable release.

ProductsStudioDownloadsDocsRelease notes
01 · WHAT IT IS FOR

One project, four jobs.

These four are what Studio actually does in this release. No other capability is claimed on this page.

01

Building a world

Keeping settings, rules and story threads together so they stay referenceable as a project grows.

02

Keeping characters consistent

Keeping a character, costume and gear the same across every part of the work.

03

Shaping a story

Ordering chapters and scenes inside the same project.

04

Designing quizzes

Turning material into questions that can be tested.

Verify before you run it.

In Windows PowerShell, hash the installer you downloaded and compare it with the manifest. Do not run the file if the values differ.

Get-FileHash .\VoidScriptor-1.2.0-rc.2-windows-x64-setup.exe -Algorithm SHA256

The timestamped Authenticode signature can be verified, but the certificate is self-issued: the publisher identity is not trusted by SmartScreen yet. SmartScreen may therefore still warn you even when the checksum matches.
