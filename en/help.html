RELEASES & PLATFORMS

About releases and platforms.

Are the products free?

The Studio preview installer can be downloaded from the canonical domain at no cost. Pricing and licensing for a stable release are not set on this page, so no figure is stated here.

Is there a macOS or Linux version?

Not yet. Studio is Windows x64 only right now. Linux and macOS are unreleased with no public date.

Where is QOWNER available?

QOWNER is intended for mobile devices. Web access is not provided, and the iOS and Android apps are not available to download yet. Use the release-interest form for mobile news.

Is there a portable build?

Not for RC.2. Only the .exe installer is published, with no portable ZIP archive.

VERIFICATION

About checking files.

How do I verify the installer?

Hash the downloaded file with SHA-256 and compare it with the official manifest. The full steps are in the getting started guide.

Why does SmartScreen warn me?

The installer's Authenticode signature uses a self-issued certificate. The signature can be verified, but the publisher identity is not trusted by SmartScreen yet, so a warning can still appear even when the checksum matches.

The checksum matches, so it is safe?

A matching checksum means the file you downloaded is the file that was published. That is not a guarantee the software is free of problems, and the decision to run it stays with you.

Where do I report a broken file?

Through the bug report page; include the filename, size and the hash value you got.

DATA & BYTE

About data and Byte.

Does Byte send my data to a server?

The Byte connection on your computer runs only at 127.0.0.1:8766 and accepts requests only from allowed addresses. It is not a public service. Never paste a token, cookie or secret into a report.

Where are projects and app data stored?

Projects live in Documents\VoidScriptor\Projects. Application files are in the VoidScriptor\state and VoidScriptor\diagnostics\crash folders. Details are in the Privacy Policy.

How do I request my data or delete my account?

Use the Data & privacy section of the dashboard. The delete button requires confirmation, and backup copies on Google Drive are not removed with it.

How do I report a bug?

Send a structured report through the bug report page with reproduction steps and the product version you are using.
