Start without guessing.

This guide includes only steps supported by available artifacts and testing. The current release is Void Scriptor Studio 1.2.0-rc.2, a release candidate for Windows x64, not a stable release.

START IN 5 MINUTES

Make a real first project.

Once Studio is available or already installed, use five minutes for one small result: create one project, add one piece of material, then reopen it for review. Do not start with an entire story world.

01

Check the release path (1 minute)

Start at the downloads page to check installer availability. When the file is available, compare its SHA-256 before running it; for RC.2, the installer is not currently verified live.

02

Open Studio and create a project (1 minute)

If Studio is already installed, open the app and create an empty project for the work you are building. Use a recognizable name instead of a temporary label.

03

Add one project core (2 minutes)

Add one world, one character, or one scene. Choose one so the first result is complete and easy to review.

04

Review and continue (1 minute)

Open the material you just created, check its consistency, and add the next part from the same project.

First-session target: when Studio is available, one saved project with one piece of material you can reopen. RC.2 has no verified public installer, so this guide does not claim that a project can be created now from this page’s download path.

The Hash value must exactly match the manifest. If it differs, do not run the installer; preserve the evidence and use the bug report form.

02 · INSTALLATION

Install and remove it through Windows.

01

Run the installer

Open VoidScriptor-1.2.0-rc.2-windows-x64-setup.exe after the checksum matches. The installer uses the default Windows location and offers an optional shortcut.

02

If Windows shows a warning

Use Technical evidence to understand the release status and verification steps before deciding in the Windows dialog.

03

Uninstall

Open Settings → Apps → Installed apps → Void Scriptor Studio → Uninstall, or run Uninstall Void Scriptor Studio from the Start Menu. Project documents and user data should not be removed without a manual check.

03 · PORTABLE / ZIP

Do not mix the two distribution formats.

Portable ZIP is not provided for RC.2.

The last audited portable artifact was marked RC.1: 34,496,233 bytes, SHA-256 1a13bbeaf1e2af1401690004cc4a34ad8f4a9e3e2b8377a0587fe79805ac071f, 497 members (494 matching payloads in CHECKSUMS.txt, plus BACA-SAYA.txt, CHECKSUMS.txt, and codesign.pub). Its public download has not been republished, so this page no longer offers a ZIP download button.

The RC.1 archive fingerprint can still be checked through the ZIP checksum manifest.

If you have an RC.1 portable archive from a trusted copy, verify its sibling .zip.sha256 hash, extract the entire folder, then run Release\void_scriptor.exe. Do not run the executable from inside the ZIP or separate the DLL/data files. Portable documentation is separate from installer documentation because the distribution flows differ.
