# Void Scriptor — Brand Mark v1

## Status
Official emblem adopted from Choirudin's supplied artwork. This package contains production-ready raster variants and a provisional wordmark lockup.

## Core mark
- `void_scriptor_emblem_master.png`: supplied master, preserved.
- `void_scriptor_emblem_transparent.png`: alpha-cropped transparent emblem for UI placement.

## Variants
- `void_scriptor_emblem_purple.png`: monochrome purple.
- `void_scriptor_emblem_white.png`: reversed/light-surface variant.
- `void_scriptor_emblem_ink.png`: dark ink variant.
- `void_scriptor_icon_<size>.png`: dark-background application icons.
- `void_scriptor_lockup_dark.png`: emblem + wordmark for dark surfaces.
- `void_scriptor_lockup_light.png`: emblem + wordmark for light surfaces.

## Palette
| Token | Hex | Use |
|---|---|---|
| Void Ink | `#0F0C19` | dark background / ink mark |
| Void Purple | `#8B5CF6` | primary brand accent |
| Violet Highlight | `#C4B5FD` | glow/highlight |
| Scriptor White | `#F5F0FF` | reversed wordmark |

## Initial usage rules
- Keep clear space around the emblem at least 1/4 of its rendered width.
- Prefer the transparent emblem on dark UI surfaces.
- Use monochrome variants when the mark is below 64 px or must be printed in one color.
- Do not stretch, rotate, recolor arbitrarily, or place the detailed master on noisy backgrounds.
- The wordmark font is provisional and must be replaced only after Choirudin approves a type direction.

## Vector source
- `void_scriptor_emblem.svg`: full-color traced vector from the supplied raster (vtracer, spline mode).
- `void_scriptor_emblem_purple.svg`, `_white.svg`, `_ink.svg`: monochrome vectors matching the raster monochrome variants.
- For print (CMYK) or sub-16 px favicons, prefer the PNG icon exports over the full-color trace.
