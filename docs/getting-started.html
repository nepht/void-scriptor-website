pwsh -File tools/verify-release.ps1 -InstallerPath ./VoidScriptor-1.2.0-rc.2-windows-x64-setup.exe -ManifestPath ./release-manifests/VoidScriptor-1.2.0-rc.2-windows-x64.sha256

02 · PEMASANGAN

Pasang dan hapus dengan jalur Windows.

01

Jalankan installer

Buka file VoidScriptor-1.2.0-rc.2-windows-x64-setup.exe setelah checksum cocok. Installer menggunakan lokasi default Windows dan menyediakan shortcut opsional.

02

Jika SmartScreen muncul

RC.2 memiliki tanda tangan Authenticode bertimestamp yang valid pada audit lokal, tetapi sertifikatnya self-issued dan belum menjadi identitas publisher yang dipercaya SmartScreen. SmartScreen tetap mungkin menampilkan peringatan. Verifikasi sumber serta checksum sebelum mengambil keputusan di dialog Windows.

03

Uninstall

Buka Settings → Apps → Installed apps → Void Scriptor → Uninstall, atau jalankan Uninstall Void Scriptor dari Start Menu. Dokumen proyek dan data pengguna tidak boleh dihapus tanpa pemeriksaan manual.

03 · PORTABLE / ZIP

Jangan campur dua bentuk distribusi.

Portable ZIP tidak disediakan untuk RC.2.

Artefak portable terakhir yang diaudit bertanda RC.1: 34.496.233 byte, SHA-256 1a13bbeaf1e2af1401690004cc4a34ad8f4a9e3e2b8377a0587fe79805ac071f, 497 member (494 payload cocok dengan CHECKSUMS.txt, ditambah BACA-SAYA.txt, CHECKSUMS.txt, dan codesign.pub). Unduhan publiknya belum dipublikasikan kembali, sehingga halaman ini tidak lagi menawarkan tombol unduh ZIP.

Sidik jari arsip RC.1 tetap dapat diperiksa melalui manifest checksum ZIP.

Jika Anda memiliki arsip portable RC.1 dari salinan tepercaya, verifikasi hash sibling .zip.sha256, ekstrak seluruh folder, lalu jalankan Release\void_scriptor.exe. Jangan menjalankan executable dari dalam ZIP atau memisahkan DLL/data. Dokumentasi portable dipisahkan dari dokumentasi installer karena alur distribusinya berbeda.

05 · DATA & KONEKSI

Ketahui apa yang tetap lokal.

Data aplikasi

Status masuk dan laporan kesalahan disimpan di folder dukungan aplikasi Windows (komponen teknisnya bernama path_provider), di dalam VoidScriptor\state dan VoidScriptor\diagnostics\crash. Lokasi folder dapat berbeda menurut konfigurasi Windows.

Proyek

Jika Anda tidak memilih lokasi sendiri, folder utama proyek berada di Documents, di dalam VoidScriptor\Projects. Lokasi pilihan Anda menjadi acuan utama; jika drive tidak tersedia, aplikasi memberi tahu bahwa lokasi cadangan sedang dipakai.

Cara masuk & koneksi Byte

Website memakai GitHub atau Google untuk masuk. Cookie sesi hanya membantu menjaga Anda tetap masuk dan tidak berisi kata sandi. Koneksi Byte opsional berjalan hanya di komputer Anda pada 127.0.0.1:8766 dan menerima permintaan dari alamat yang diizinkan. Jangan menyalin token, cookie, atau rahasia ke laporan.
