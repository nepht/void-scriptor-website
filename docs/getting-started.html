02 · PEMASANGAN

Pasang dan hapus dengan jalur Windows.

01

Jalankan installer

Buka file VoidScriptor-1.2.0-rc.2-windows-x64-setup.exe setelah checksum cocok. Installer menggunakan lokasi default Windows dan menyediakan shortcut opsional.

02

Jika SmartScreen muncul

RC.2 memiliki tanda tangan Authenticode bertimestamp yang valid pada audit lokal, tetapi sertifikatnya self-issued dan belum menjadi identitas publisher yang dipercaya SmartScreen. SmartScreen tetap mungkin menampilkan peringatan. Verifikasi sumber serta checksum sebelum mengambil keputusan di dialog Windows.

03

Uninstall

Buka Settings → Apps → Installed apps → Void Scriptor → Uninstall, atau jalankan Uninstall Void Scriptor dari Start Menu. Dokumen proyek dan data pengguna tidak boleh dihapus tanpa pemeriksaan manual.

03 · PORTABLE / ZIP

Jangan campur dua bentuk distribusi.

Portable ZIP tersedia sebagai artefak publik yang sudah diaudit.

ZIP berukuran 34.496.233 byte dengan SHA-256 1a13bbeaf1e2af1401690004cc4a34ad8f4a9e3e2b8377a0587fe79805ac071f. Isinya memiliki 497 member: 494 payload cocok dengan CHECKSUMS.txt, ditambah BACA-SAYA.txt, CHECKSUMS.txt, dan codesign.pub sebagai metadata paket.

Artefak portable ini masih bertanda RC.1; RC.2 saat ini hanya tersedia sebagai installer Windows.

05 · DATA & KONEKSI

Ketahui apa yang tetap lokal.

Data aplikasi

State autentikasi dan artefak diagnostik menggunakan direktori application-support Windows yang diberikan oleh path_provider, di bawah subfolder VoidScriptor\state dan VoidScriptor\diagnostics\crash. Lokasi fisik dapat berbeda menurut konfigurasi Windows.

Proyek

Tanpa lokasi custom, root proyek default berada di direktori Documents platform di bawah VoidScriptor\Projects. Lokasi custom yang sehat menjadi sumber kebenaran; jika drive hilang, aplikasi memberi status fallback.

OAuth & Byte Bridge

Website memakai GitHub/Google OAuth dan cookie sesi HttpOnly; kata sandi tidak diterima. Byte Bridge opsional berjalan lokal pada 127.0.0.1:8766 dan hanya menerima origin yang diizinkan. Jangan menyalin token, cookie, atau secret ke laporan.
