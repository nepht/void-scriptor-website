      Belum tersedia

      Checksum membantu mendeteksi kerusakan atau perubahan setelah unduh. Nilai tersedia di manifest checksum; ini belum menggantikan tanda tangan kode.

      Verifikasi lokal: berkas tidak dikirim ke mana pun. Hash dihitung di peramban Anda.

      Tindakan

      Keluar akan menghapus sesi di peramban ini seketika.

      Data & privasi

      Profil akun, cara masuk, dan sesi login tersimpan di basis data akun untuk website dan aplikasi Windows RC2. Preferensi Byte, checklist, dan ringkasan ruang kerja tetap lokal di peramban ini. Ekspor menyalin ringkasan akun dan data lokal ke berkas; tombol lokal hanya menghapus data browser, sedangkan tombol Hapus akun dan data server menghapus akun tersimpan.

      Yakin? Data Byte, checklist, dan ringkasan lokal akan dihapus, lalu sesi peramban ini dicabut. Ini hanya menghapus data lokal. Untuk menghapus akun tersimpan dan data server, gunakan tombol Hapus akun dan data server di bawah.

      Cabut izin di penyedia

      Penghapusan akun bersifat permanen. Profil, akun Google/GitHub yang terhubung, semua sesi, snapshot cloud, dan token Google Drive yang tersimpan akan dihapus. File yang sudah ada di Google Drive tidak ikut dihapus.

      Belum ada tindakan.
